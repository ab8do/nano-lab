# Nano Lab

**تفاعل بالإيماءات والصوت على أردوينو نانو وشاشة OLED بدقة 128×64**

[English](README.md) · [Français](README.fr.md) · **الموقع:** `https://ab8do.github.io/nano-lab/`

## الملخّص

ذاكرة أردوينو نانو 2 كيلوبايت فقط، ولا تكفي لمعالجة صور الكاميرا أو الكلام. يدرس هذا المستودع إلى أي مدى يمكن استعمال هذه اللوحة كـ«طرف تفاعل» عندما يتولى حاسوب محمول الإدراك (رؤية وكلام وذكاء اصطناعي) وتقتصر اللوحة على تحديث الحالة والرسم على شاشة OLED بحجم 0.96 بوصة وبلونين. يضم المستودع ثلاثة نماذج متدرجة التعقيد: **(1) الداينو**: قناة أوامر مفردة (بايت واحد لكل قفزة). **(2) ألعاب الإيماءات**: تدفق مستمر لحالة اليد (4 بايتات) يقود أربع ألعاب. **(3) روبو**: وكيل محادثة بوجه معبّر يُرسم بذاكرة محدودة، ويمكن تبديل «دماغه» بين نموذج سحابي ونسخة موفّرة للتوكنز ونسخة محلية بالكامل. تتوفر كل الأكواد ومواصفات البروتوكول وموقع تعريفي بثلاث لغات.

## أسئلة البحث

1. هل يمكن لمتحكم ATmega328P (ذاكرة 2 كيلوبايت) تشغيل ألعاب تفاعلية تُتحكم فيها بإيماءات اليد عبر وصلة تسلسلية فقط؟
2. ما أصغر بروتوكول تسلسلي يكفي لكل نمط تفاعل (أمر منفرد، حالة مستمرة، محادثة)؟
3. كيف يُرسم وجه معبّر (انتقال سلس بين العواطف ونظر وتزامن الفم) ضمن ذاكرة اللوحة؟
4. ما المفاضلات العملية بين الذكاء السحابي والسحابي الموفّر والمحلي (التكلفة والحصص والإنترنت والتأخير والجودة)؟

## المشاريع الثلاثة

| المشروع | الإدخال | الرسالة التسلسلية | الملفات |
|---|---|---|---|
| الداينو | رفع اليد (MediaPipe Hands، السبابة أعلى المعصم بأكثر من 0.2 من ارتفاع الصورة) | الحرف `J` بسرعة 9600 باود | `firmware/dino`، `software/dino` |
| ألعاب الإيماءات | موضع الكف وعدد الأصابع | `255, x, y, f` بسرعة 57600 باود | `firmware/gesture-games`، `software/gesture-games` |
| روبو | الصوت (ميكروفون) ووجه المستخدم (كاميرا) | `255,x,y` نظر، `254,c` أوامر، `253,v` مستوى الصوت، `252,e` الطاقة | `firmware/robo-face`، `software/robo` |

الألعاب الأربع: Flappy Bird (اقفل القبضة ثم افتح اليد) وPong (ارتفاع اليد = المضرب) وSnake (إزاحة اليد عن المنتصف = الاتجاه) وShooter (أفقيًا؛ إطلاق تلقائي). التفاصيل الرقمية في [README.md](README.md) والموقع.

## التوصيل (لكل المشاريع)

| طرف الشاشة | طرف النانو |
|---|---|
| GND | GND |
| VCC | 5V |
| D0 (CLK) | D13 |
| D1 (MOSI) | D11 |
| RES | D8 |
| DC | D9 |
| CS | D10 |

يجب **لحام** دبابيس النانو، وإلا بقيت الشاشة سوداء. إن لم تعمل الشاشة فجرّب سطر SH1106 في الكود.

## التشغيل السريع

```bash
git clone https://github.com/ab8do/nano-lab.git
cd nano-lab
pip install -r software/dino/requirements.txt
python software/dino/dino_controller.py   # غيّر PORT داخل الملف أولًا
```

لروبو بـ Gemini ضع المفتاح في متغير البيئة `GEMINI_API_KEY` ولا ترفعه أبدًا إلى GitHub.

## حالة التحقق

ُفحصت صياغة الأكواد محليًا، ويُترجم CI الأكواد لـ `arduino:avr:nano`. شُغّل الداينو وروبو (v3 مع Gemini) على الجهاز من قبل المؤلف، أما ألعاب الإيماءات والنسختان الموفّرة والمحلية فلم يُبلَّغ بتجربتها بعد. **لم تُجمع قياسات كمية** (تأخير ودقة)، وبروتوكول القياس المقترح في `documentation/validation.md`.

## الخصوصية

الكاميرا تُعالج محليًا ولا تُرفع. في نسخ Gemini يُرسل تسجيل صوتك إلى خوادم Google. في النسخة المحلية لا يُرسل الصوت لأي جهة، وخدمة edge-tts ترسل النص المراد نطقه فقط.

ترخيص MIT. للاقتباس استعمل `CITATION.cff`. طُوّر المشروع تدريجيًا بمساعدة نموذج ذكاء اصطناعي (Claude من Anthropic) في صياغة الأكواد والتوثيق، أما قرارات التصميم وتركيب العتاد والاختبار فمن عمل المؤلف.
